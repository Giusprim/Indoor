1Importa Brani

Formato: una riga per brano → Titolo — Artista | BPM | mm:ss oppure Titolo — Artista | BPM | durata_sec

2Setup Lezione

3Analisi AI

Claude analizza la tua playlist e assegna zona FC, RPM, resistenza, manubrio, tecnica con segmenti temporali e focus coaching per ogni brano.

⚠️ Importa prima i brani (Step 1) prima di eseguire l'analisi.

4Revisione Brani

I brani analizzati appariranno qui.

5Genera Player HTML

I parametri Spotify sono già pre-compilati. Inserisci solo l'URI della playlist di questa lezione.

Copia il link Spotify → tasto destro sulla playlist → Condividi → Copia link. Il formato sarà: https://open.spotify.com/playlist/XXXX — il planner lo converte automaticamente in URI.

✅ index.html pronto — Clicca per scaricare
Dopo il download:
1. Vai su github.com/Giusprim/Indoor

3. Oppure usa Git: git add index.html && git commit -m "nuova lezione" && git push
